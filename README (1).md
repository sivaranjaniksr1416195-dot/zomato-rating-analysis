# Zomato Rating Analysis

## 📌 Overview
This project analyzes Zomato restaurant data to understand the factors influencing restaurant ratings. Using exploratory data analysis (EDA) and data visualization techniques, the project uncovers patterns related to location, cuisine, cost, and customer preferences.

## 🎯 Objectives
- Analyze restaurant ratings and reviews
- Identify key factors affecting ratings
- Perform data cleaning and preprocessing
- Visualize insights for better decision-making

## 🧠 Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook

## 📊 Dataset
- **Source:** Zomato Dataset
- **Features:** Restaurant name, location, cuisines, cost, rating, votes
- **Type:** Structured CSV data

## 🔍 Analysis Performed
- Data cleaning and handling missing values
- Rating distribution analysis
- Location-wise and cuisine-wise comparison
- Cost vs rating analysis

## 📈 Results & Insights
- Restaurants with moderate pricing tend to receive higher ratings
- Certain locations show consistently better ratings
- Popular cuisines attract more customer engagement
